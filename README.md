# meme_tycoon

Chtěl bych vytvořit jednoduchou 2D idle tycoon hru - název vymysli si
Princip hry:
Hráč začíná s určitým množstvím Coins
Za Coins nakupuje různé Gen Alpha meme postavičky (Brainroty)
Každá postavička automaticky vydělává Coins za sekundu
Vydělané Coins hráč investuje do dalších a lepších Brainrotů
Postavičky mají různé rarity (Common, Rare, Epic, Legendary, Mythical atd.)
Možnost vylepšování postaviček a zvyšování jejich produkce
Postupně se odemykají nové lokace a dražší postavičky
Do budoucna možnost Prestige systému, achievementů a leaderboardů
Grafika: Jednoduchá 2D vektorová/cartoon grafika, barevný a trochu meme styl
Hlavní myšlenka: Nakupovat meme postavičky, nechat je vydělávat peníze a postupně vybudovat co největší Brainrot impérium.
